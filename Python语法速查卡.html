# 名字 长什么样 怎么读 用在项目哪一步
1 导入 import pandas as pd 把 pandas 拿进来，以后叫它 pd 每个 Notebook 的第一格
2 变量赋值 df = ... 把右边算出来的东西，起个名叫 df 读完数据后，那张表就叫 df
3 函数调用 pd.read_csv(路径, encoding="utf-8-sig") 执行 read_csv 这件事，括号里是要给它的东西 第 3 章读数据
4 字符串 "单价"   "区域" 引号里的字原样保留，不参与计算 所有列名都要加引号
5 取一列 df["单价"] 从 df 里把单价那一列单独拎出来 算均价、算比例都要先取列
6 点号连写 df.groupby("区域")["单价"].mean() 分组 → 取列 → 求平均，一步一步往下接 第 5、6、7 章全部结论

二、项目每一行代码，翻译成大白话左边照抄，右边是你的理解

import pandas as pd把 pandas 这个库拿进来，以后简写成 pd
df = pd.read_csv(r"D:\...\天津二手房_2026年10月.csv", encoding="utf-8-sig")读这个 csv 文件，存成一张表，名字叫 df
df.head()给我看前 5 行，确认数据长什么样
df.shape告诉我几行几列（注意：不带括号）
df.info()每列是什么类型、有没有缺值
df["单价"].mean()单价这一列，求平均数
df.groupby("区域")["单价"].mean()按区域分组，每组各算一个单价平均数
.sort_values(ascending=False)排个序，从大到小
df["面积段"] = pd.cut(df["面积"], bins=[0,60,90,120,999], labels=["60平以下","60-90平","90-120平","120平以上"])把面积切成 4 档，结果存成一个新列，叫面积段
df.groupby("天数段")["是否降价"].apply(lambda s: (s == "是").mean())每组里"是"占多少比例，也就是降价概率
lambda 是个没名字的小函数，这行先照抄，第 7 周再拆开讲
.plot(kind="bar")把这些数画成柱状图
plt.savefig(r"D:\...\图1_各区均价.png", dpi=150)把图存成图片文件

三、常用命令小抄照着敲，不用背

命令 作用 什么时候用
df.head(10)看前 10 行刚读完数据，先瞄一眼
df.columns列出所有列名报 KeyError 时，先查真实列名
df.shape几行几列确认数据量对不对
df.describe()数值列的最大最小平均发现异常值
df["是否降价"].value_counts()每个值各出现几次看分类分布
.round(0)保留 0 位小数数字太长发虚
.groupby("区域", observed=True)分组（加了 cut 分档后要加这个）第 6、7 章必须加，否则会警告
pd.read_csv?弹出官方说明和例子不记得参数怎么写的时候

四、报错对照八成是这五个

  • NameError: name 'df' is not defined
    df 那一格没跑。从最上面开始，按顺序重新跑一遍。
  • FileNotFoundError
    路径错了。去文件夹里复制完整路径，粘贴进来，别手打。
  • UnicodeDecodeError
    少了 encoding="utf-8-sig"。
  • KeyError: '单价'
    列名不对。先跑 df.columns 看真实名字，多半是空格或全半角。
  • 中文变成方块
    少了 plt.rcParams 那两行字体设置。
