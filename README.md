# 天津二手房数据分析

用天津二手房挂牌数据做的一次探索性数据分析（EDA）练习，目标是把 pandas 的读取、清洗、分组聚合和可视化完整走一遍。

> 状态：进行中。每次分析能跑通就 commit 一次。

## 数据

文件：`天津二手房_2026年10月.csv`

| 字段 | 含义 |
|---|---|
| 房源编号 | TJ0001 格式的唯一编号 |
| 区域 / 小区 | 所在行政区与小区名 |
| 户型 / 面积 / 楼层 / 朝向 | 房源基本属性 |
| 挂牌总价 | 万元 |
| 单价 | 元/平方米 |
| 挂牌天数 | 已挂牌时长 |
| 是否降价 / 降价幅度 | 挂牌期间是否调价 |
| 挂牌日期 | 挂牌时间 |
